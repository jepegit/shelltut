# 10 — jq

Requires `jq`. Data file: `playground/data/cells.json`.

## Goals

Query and reshape JSON from the terminal.

## Drills

1. Pretty-print the file: `jq . playground/data/cells.json`
2. Get the experiment name.
3. List all cell ids.
4. Select cells with `status == "ok"`.
5. Get chemistries of ok cells only.
6. Compute average `capacity_mah` of all cells.
7. Build a compact table-like view:

```bash
jq -r '.cells[] | [.id, .chemistry, .status] | @tsv' playground/data/cells.json
```

## Stretch

- Filter `cycles > 100` and output JSON again
- Combine with shell: `jq -r '.cells[].id' ... | while read -r id; do echo "id=$id"; done`
